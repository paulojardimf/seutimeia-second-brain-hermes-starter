# Skills autorais (`skills/autorais/`)

## Propósito
Reúne as skills criadas na própria operação: as que o Hermes escreve a partir das interações com o time (um processo que se repete, um jeito de montar um relatório, um fluxo de uma ferramenta) e que não vêm automáticas com o Hermes nem com o método. É a parte do pilar **Skills e rotinas** que é só da sua empresa.

## Estrutura
Uma pasta por skill, com o nome da skill e um `SKILL.md` no formato do Hermes:

```
skills/autorais/<nome-da-skill>/SKILL.md
```

## Como uma skill nasce
1. Alguém pede ao Hermes uma tarefa que se repete, ou o Hermes percebe a repetição na captura diária.
2. O Hermes propõe a skill no canal, com gatilho, entradas e saída esperada.
3. Com a aprovação de quem pediu, cria a skill no Hermes e grava a cópia aqui, em um commit.
4. A skill entra no índice abaixo, com data, autor do pedido e estado.

## Regras
- Skill nova exige o nome de quem pediu e a data.
- Sem segredos, ids de cliente ou dados pessoais dentro da skill.
- Skill alterada tem o motivo no commit; skill aposentada vai para `historico/`.
- As skills do método (`installable/` e `starter/`) não são editadas aqui; copie e adapte para `autorais/`.
