# Mapa de skills

## Instaláveis (o Hermes instala com `scripts/install-onboard-skill.sh`)
| Skill | Papel | Quando roda |
|---|---|---|
| `seutimeia-second-brain-onboard` | confere o ambiente, entrevista pelo Discord, preenche o repositório, cria canais e rotinas | uma vez, e para retomar |
| `segundo-cerebro-captura` | lê as interações do dia e grava decisões, fatos, aprendizados, erros e lições | rotina diária |
| `segundo-cerebro-revisao` | revisões semanal, quinzenal e mensal | rotinas periódicas |

## Skills-base de apoio (em `skills/starter/`)
| Skill | Papel | Quando usar |
|---|---|---|
| `cerebro` | boot de contexto com leitura do repositório | início de trabalho em projeto |
| `rotina` | cockpit diário curto | começo do dia |
| `salve` | grava o que importa ao fim de uma sessão | fechamento de trabalho relevante |
| `higiene-semanal` | revisão estrutural do repositório | manutenção semanal |
| `varredura-de-sessoes` | consolidado executivo de sessões | semanal, quando há volume |

## Ordem recomendada
1. instalar as três skills instaláveis;
2. rodar o onboarding;
3. ligar o diário e observar uma semana;
4. ligar as revisões;
5. adaptar as skills-base ao que a equipe realmente usa.

## Skills que normalmente nascem depois
Propostas comerciais, rotinas de uma ferramenta específica (ERP, CRM, e-mail) e skills de projeto ou cliente. Nascem de um fluxo real escolhido pela equipe, não de uma lista inicial.
