# Discord

## Papel
Canal onde as pessoas falam com o Hermes e onde as rotinas entregam resultado. No segundo cérebro, também é a fonte das interações que viram memória.

## Estrutura recomendada
| Canal | Para quê |
|---|---|
| canal principal do Hermes | pedidos do dia a dia, em threads |
| `diario` | resumo diário das interações |
| `revisoes` | revisões semanal, quinzenal e mensal |
| `decisoes-e-licoes` | consulta rápida de decisões e lições |
| `cerebro-testes` | ensaio das rotinas |

A skill de onboarding propõe esta estrutura e só cria o que ainda não existe, depois de aprovação.

## O que decidir
- quem pode falar com o Hermes (lista nominal);
- quem lê cada canal;
- se mensagens diretas ficam fechadas (recomendado até haver decisão explícita);
- quem pode pedir correção ou exclusão de registros.

## O que documentar aqui
- servidor e ids dos canais usados pelas rotinas;
- permissões do bot;
- quando e por quem a lista de pessoas autorizadas mudou.

## Riscos
- excesso de canais mal governados;
- permissão ampla demais para o bot;
- credenciais coladas no chat;
- membros novos entrando sem decisão nominal.
